# Clipboard-Manager
The Clipboard Manager is a Python automation project that continuously monitors clipboard activity and stores copied text history automatically.

# Clipboard Manager

## Project Overview

The Clipboard Manager monitors and stores copied text history automatically using Python.

The project tracks clipboard changes and maintains a history of copied content.


# Features

- Clipboard history tracking
- Automatic monitoring
- Lightweight utility tool
- Productivity enhancement


# Technologies Used

- Python
- pyperclip


# Installation

Install required library:

pip install pyperclip

# Run Project

python clipboard_manager.py


# How It Works

1. Monitor clipboard
2. Detect copied text
3. Store history
4. Display saved clipboard items
